# Культурный гид — веб-версия

Аудиопутеводитель по городам России для браузера телефона: открыл ссылку или QR-код — и пошёл.
Работает на iPhone и Android без установки.

Сейчас в гиде один город — **Троицк (Челябинская область)**: 14 объектов и 4 тематических маршрута.
Формат данных сразу рассчитан на много городов: город — это папка с файлами (см. [пакет города](docs/city-package.md)).

## Что уже есть

- Выбор города, в том числе по геопозиции (спрашивается только по нажатию).
- Страница города: маршруты с длительностью, длиной и числом остановок, все объекты.
- Маршрут: остановки по порядку.
- Карточка объекта: рассказ, даты, люди (архитектор, заказчик…), статус памятника, источники.
- Крупный шрифт (кнопка «Аа», запоминается), фокус и заголовки для экранного чтеца, тёмная тема.
- Логика ведения по маршруту с тестами: прибытие после 5 секунд в радиусе, срезанный путь, «Я на месте».
- Проверка пакетов городов: формат, ссылки, координаты в районе города, источники для опубликованного, права на фото.

## Дальше

1. Карта: своя подложка MapLibre + тайлы OpenFreeMap, пешеходный граф из OSM, навигатор.
2. Аудио: озвучка через Яндекс SpeechKit / ElevenLabs по словарю, плеер, разблокировка звука на iOS.
3. Свободная прогулка: рассказ о ближайших объектах по ходу движения (поле `note`).
4. Фактчекинг Троицка по первоисточникам и проход маршрутов на месте (отчёт `npm run content`).
5. Хостинг, домен, выкладка из CI, og-карточка, счётчик запусков.
6. «Было/стало» — когда найдутся архивные фото с правами (поле `then_now`).

## Запуск

```bash
npm ci
npm run dev          # http://localhost:5173
npm run check        # всё, что проверяет CI: данные, типы, тесты, сборка, smoke-тест
```

| Команда | Что делает |
|---|---|
| `npm run content` | проверяет пакеты городов и собирает их в `public/data/`; печатает отчёт: ошибки, предупреждения, редакционные пункты |
| `npm run content:check` | только проверка |
| `npm test` | юнит-тесты (Vitest) |
| `npm run build` | сборка в `dist/` — статические файлы для любого хостинга |
| `npm run smoke` | smoke-тест собранного сайта в Chromium с экраном iPhone; снимки — в `test-results/` |

## Где что лежит

| Путь | Что это |
|---|---|
| `content/` | **Оригиналы** текстов и маршрутов, по папке на город |
| `src/content/schema.ts` | формат пакета города (zod): проверка и типы |
| `src/content/bundle.ts` | формат собранных данных, которые загружает приложение |
| `src/lib/` | логика без интерфейса: ведение, геометрия, оценка времени, форматирование — с тестами |
| `src/screens/` | экраны: выбор города, город, маршрут, объект |
| `tools/build-content.ts`, `tools/content.ts` | проверка и сборка пакетов городов |
| `tests/smoke.mjs` | smoke-тест в браузере |
| `public/.htaccess` | кэширование на Apache-хостинге |
| `docs/city-package.md` | формат пакета города и как добавить город |
| `docs/decisions.md` | принятые решения и уроки «Маленького каравана» |

Проверки на каждый pull request — workflow **Checks** (`.github/workflows/checks.yml`).
