# Решения и уроки

Что решено и почему. Многое взято из опыта «Маленького каравана»
(qwest65/malenkiy-karavan-web, qwest65/malenkiy-karavan) и Android-версии гида (qwest65/culture-guide).

## Принято

| Решение | Почему |
|---|---|
| **Один город — Троицк, но формат сразу рассчитан на много городов** | Троицк знаем лучше всего. Новые города — это новые папки в `content/cities/`, код менять не нужно |
| **Содержание — файлы в репозитории, а не админка** | История правок, ревью через pull request, проверки в CI. Админка появится, только если её действительно попросят авторы-партнёры |
| **Статусы draft / review / published и источники обязательны для публикации** | Гид должен быть профессиональным: за каждым фактом стоит источник и человек, который его проверил |
| **Редакционные пометки (`editorial`) живут рядом с текстом, но в приложение не попадают** | Список «что доделать» виден в отчёте сборки, а не в отдельной таблице |
| **Без service worker** | Офлайн не нужен. Без service worker не будет главной проблемы «Каравана» — телефоны со старой версией. Вместо него: файлы с хэшем в имени, `no-cache` для `index.html` и `cities.json` (`public/.htaccess`) |
| **Адреса экранов во фрагменте (`#/troitsk/place/…`)** | Работают на любом хостинге без настройки сервера и в QR-кодах |
| **Preact + Vite + TypeScript, системные шрифты** | Лёгкая страница (≈ 11 КБ JS в gzip) быстро открывается по мобильному интернету. Со сторонних серверов ничего не грузится |
| **Схема формата в коде (zod), типы — из неё же** | Проверка данных и приложение не разойдутся |
| **Ведение: прибытие после 5 секунд в радиусе 45 м** | Перенесено из `GuidanceEngine.kt`, плюс урок «Каравана»: одиночный скачок GPS не засчитывается |
| **Геопозиция — только по нажатию** | Так требует iPhone. Если отказ, человеческое объяснение и выбор города вручную |
| **Всё как в веб-версии «Маленького каравана»** | Своя подложка карты (MapLibre + OpenFreeMap в `public/map/`), граф улиц из OSM без дворов и маршрутизация в телефоне, голос Яндекс SpeechKit (ermil), «Начать» разблокирует звук, разовый запрос геопозиции + слежение + перезапуск, «Открыть в Safari», компас на iPhone по нажатию, прибытие 5 с в радиусе |
| **Пути маршрутов считает сборка, «от меня до точки» — телефон** | Один и тот же код (`src/lib/streets.ts`) и один граф: длины маршрутов в карточках совпадают с тем, что покажет навигатор |
| **Озвучка — с хэшем текста** | Поправили текст — сборка скажет, что озвучка устарела; Voice переозвучит только изменённое |
| **Карта грузится отдельным модулем** | MapLibre весит ~300 КБ (gzip) — нужен только на экране прогулки, страницы города и объектов остаются лёгкими |
| **Адрес — culture-guide.mooo.com, домашний сервер** | Бесплатно и в России: Caddy (HTTPS) → Nginx Proxy Manager → nginx со статикой; сервер сам забирает проверенную сборку из `gh-pages`. Адрес выбран один раз — на нём хранятся настройки и прогресс в телефонах. GitHub Pages — запасная копия |

## Уроки «Маленького каравана», которые ещё впереди

Уже сделано: своя карта, граф улиц, голос Яндекса со словарём, разблокировка звука, компас по нажатию, «Открыть в Safari», «Я на месте».

| Урок | Где учтём |
|---|---|
| Маршрут нужно пройти ногами | Пункт в `editorial.todo` у города. Координаты из «Каравана» проверены на месте в сентябре 2026 |
| GitHub Pages не даёт HTTPS для .ru/.рф, Cloudflare тормозит | Сделано: домашний сервер в России, выкладка без FTP — сервер сам забирает сборку |
| localStorage привязан к домену | Выбран: culture-guide.mooo.com |
| Карточки ссылок кэшируются мессенджерами | og-теги и картинка `og.jpg` есть (адрес GitHub Pages) — поменять вместе с доменом; @WebpageBot, `?v=` |
| Telegram API недоступен из Яндекс Облака | Учесть, если появятся уведомления или отзывы |
| Для гранта нужны цифры | Анонимный счётчик «открыли / начали / дошли до конца», как в «Караване» |

## Данные Троицка: откуда взялись

- 10 объектов и 4 маршрута — из Android-каталога `culture-guide` (`app/src/main/assets/catalog.json`, ветка `dev`).
- 4 объекта (бронзовый верблюд, «Городовой», памятник Крылову, гостиница «Центральная») и короткие
  заметки — из справок для взрослых «Маленького каравана» (`data/route.json`).
- Координаты общих объектов — из «Каравана» (проверены на месте). Исключение — торговые ряды:
  там расхождение около 200 м, оставлена координата каталога у адреса. Пункт записан в `editorial.todo`.
- Даты, люди и статус памятника перенесены только из текстов источников. Ничего нового не добавлено.
