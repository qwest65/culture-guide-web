# Культурный гид — веб-версия

Путеводитель по историческим городам России: достопримечательности, их история и пешеходные маршруты
с рассказом о каждом месте. Работает в браузере телефона: открыл ссылку или QR-код — и пошёл.

### 👉 [qwest65.github.io/culture-guide-web](https://qwest65.github.io/culture-guide-web/) — временный адрес, пока не выбраны домен и российский хостинг

Сейчас в гиде один город — **Троицк (Челябинская область)**: 14 объектов и 4 тематических маршрута.
Всё устроено как в веб-версии «Маленького каравана»: своя карта, пешеходные пути по главным улицам,
голос Яндекс SpeechKit, прибытие по GPS после 5 секунд у точки.
Формат данных сразу рассчитан на много городов: город — это папка с файлами (см. [пакет города](docs/city-package.md)).

## Что уже есть

- Выбор города, в том числе по геопозиции (спрашивается только по нажатию).
- Страница города: маршруты с длительностью, длиной по улицам и числом остановок, все объекты.
- **Прогулка по маршруту** — карта на весь экран, как навигатор:
  - своя подложка карты (MapLibre + кусочки OpenFreeMap в `public/map/<город>/`) — не зависит от чужих серверов карт;
  - путь по главным улицам и тротуарам, без дворов (граф улиц из OSM, считается прямо в телефоне);
    свернули — путь перестраивается от того места, где вы стоите;
  - повороты на плашке и голосом («Через 40 м — поверните налево»), карта повёрнута по пути,
    сдвинули пальцем — через 8 секунд вернётся к вам; кнопки «весь маршрут», «север», компас на iPhone по нажатию;
  - прибытие — 5 секунд в радиусе 45 м, одиночный скачок GPS не считается; сразу звучит рассказ;
  - «Я на месте» и «Пропустить», если геопозиции нет; подсказка «Открыть в Safari / браузере» во встроенных браузерах мессенджеров;
  - звук разблокируется кнопкой «Начать прогулку» (iPhone); экран не гаснет; прогресс запоминается.
- Карточка объекта: рассказ голосом, даты, люди (архитектор, заказчик…), статус памятника, источники.
- Крупный шрифт (кнопка «Аа», запоминается), фокус и заголовки для экранного чтеца, тёмная тема.
- Проверка пакетов городов: формат, ссылки, координаты в районе города, пути по улицам,
  источники для опубликованного, права на фото, устаревшая озвучка.

## Озвучка

Голос рассказчика — Яндекс SpeechKit, **ermil**, как в «Маленьком караване». 9 рассказов из 14
взяты оттуда готовыми (тот же текст и голос). Остальные 5 рассказов и фразы навигатора
(«Поверните налево», «Мы почти на месте»…) озвучит workflow **Voice**:

1. Settings → Secrets and variables → Actions → New repository secret: `YANDEX_SPEECHKIT_KEY` —
   API-ключ сервисного аккаунта Яндекс Облака с ролью `ai.speechkit-tts.user` (можно тот же, что у «Каравана»).
2. Actions → **Voice** → Run workflow → `missing`. Озвучит новое и изменённое, закоммитит и выложит сайт.

Поменяли текст — сборка предупредит «текст изменился после озвучки»; снова запустите Voice → `missing`.
Как читать инициалы, века и ударения — `content/cities/<город>/lexicon.json` и `content/voice.json`;
проверить, что уйдёт в синтез: `python3 tools/generate_audio.py --print troitsk`.

## Выкладка

Workflow **Deploy** после каждого изменения в `main` и в рабочей ветке прогоняет все проверки
(включая smoke-тест в браузере) и кладёт собранный сайт в ветку `gh-pages`.
Один раз нужно включить: Settings → Pages → Source: **Deploy from a branch**, ветка `gh-pages`, папка `/ (root)`.

Это временно: для доменов .ru/.рф GitHub Pages не выдаёт HTTPS, а Cloudflare в России тормозит,
поэтому для запуска — российский хостинг с выкладкой из CI, как у «Маленького каравана».
`public/.htaccess` для него уже лежит.

| Workflow | Когда | Что делает |
|---|---|---|
| Checks | каждый pull request | данные, типы, тесты, сборка, smoke-тест; снимки экранов в артефакте |
| Deploy | push в `main` / рабочую ветку | Checks + выкладка на GitHub Pages |
| Voice | вручную | озвучка Яндекс SpeechKit → коммит → выкладка |
| Map | вручную | своя подложка карты города с OpenFreeMap → коммит → выкладка |
| Streets | правка `walking.json` или вручную | граф улиц из OpenStreetMap → коммит → выкладка |
| Photos | правка `tools/fetch_photos.py` или вручную | кандидаты в фото с Викисклада (свободные лицензии) — архивом для просмотра; выбранные кладутся в `public/photos/<город>/` и в поле `photos` |

## Дальше

1. Озвучить оставшиеся 5 рассказов и фразы навигатора (нужен секрет, см. выше).
2. Свободная прогулка: рассказ о ближайших объектах по ходу движения (поле `note`).
3. Фактчекинг Троицка по первоисточникам и проход маршрутов на месте (отчёт `npm run content`).
4. Домен, российский хостинг с автовыкладкой, счётчик запусков.
5. «Было/стало» — когда найдутся архивные фото с правами (поле `then_now`).

## Запуск

```bash
npm ci
npm run dev          # http://localhost:5173
npm run check        # всё, что проверяет CI: данные, типы, тесты, сборка, smoke-тест
```

| Команда | Что делает |
|---|---|
| `npm run content` | проверяет пакеты городов и собирает их в `public/data/`; печатает отчёт: ошибки, предупреждения, редакционные пункты |
| `npm run content:check` | только проверка |
| `npm test` | юнит-тесты (Vitest) |
| `npm run build` | сборка в `dist/` — статические файлы для любого хостинга |
| `npm run smoke` | smoke-тест собранного сайта в Chromium с экраном iPhone; снимки — в `test-results/` |

## Где что лежит

| Путь | Что это |
|---|---|
| `content/` | **Оригиналы** текстов и маршрутов, по папке на город |
| `src/content/schema.ts` | формат пакета города (zod): проверка и типы |
| `src/content/bundle.ts` | формат собранных данных, которые загружает приложение |
| `src/lib/` | логика без интерфейса: ведение, геометрия, оценка времени, форматирование — с тестами |
| `src/screens/` | экраны: выбор города, город, маршрут, объект, прогулка |
| `src/walk/` | прогулка: ведение (`session.ts`), карта (`map.ts`), геопозиция, звук, компас |
| `src/lib/streets.ts` | граф улиц, путь по улицам, повороты — из «Маленького каравана» |
| `tools/build-content.ts`, `tools/content.ts` | проверка и сборка пакетов городов, пути маршрутов по улицам |
| `tools/build_map.py` | своя подложка карты города (workflow Map) |
| `tools/build_streets.py` | граф улиц из OpenStreetMap (workflow Streets) |
| `tools/generate_audio.py` | озвучка Яндекс SpeechKit (workflow Voice) |
| `public/map/<город>/` | своя карта: стиль, кусочки, значки, шрифты |
| `public/audio/` | озвучка: рассказы по городам и общие фразы, `manifest.json` — что с какого текста озвучено |
| `tests/smoke.mjs` | smoke-тест в браузере |
| `public/.htaccess` | кэширование на Apache-хостинге |
| `docs/city-package.md` | формат пакета города и как добавить город |
| `docs/decisions.md` | принятые решения и уроки «Маленького каравана» |
| `.github/workflows/` | Checks, Deploy, Voice, Map, Streets |
